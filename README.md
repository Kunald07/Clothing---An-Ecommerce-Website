# Clothing E-Commerce Website 👕🛍️

A modern and responsive frontend clothing e-commerce website developed using **HTML**, **CSS**, and **JavaScript**. This project showcases an attractive online shopping interface with featured products, latest collections, testimonials, and responsive navigation.

## 📌 Features

- Responsive and mobile-friendly design
- Modern landing page with hero banner
- Product listing section
- Featured and latest products
- Shopping cart interface
- About Us and Contact pages
- Customer testimonials
- Smooth animations using GSAP
- Attractive UI with Font Awesome and Boxicons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP Animation Library
- Boxicons
- Font Awesome
